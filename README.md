# HILEX — Africa Digital Economy Mission Hub

Free, mobile-first educational hub designed for GitHub Pages.

## Publish
1. Create a GitHub repository, e.g. `hilex-africa`.
2. Upload all files in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, then `main` and `/ (root)`.
5. Save and open the GitHub Pages URL.

Before publishing, replace the placeholder Pi/application links in `index.html` with the live URLs.
